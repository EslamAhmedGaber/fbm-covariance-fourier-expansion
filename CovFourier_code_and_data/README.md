# CovFourier: code, protocol, results and public data

Reproduces every number, table and figure of the manuscript "CovFourier: Gaussian-process learning with two-sided
evidence bounds for fractional Brownian motion" and its Supplementary Material.

- `experiments/PROTOCOL.md` - designs, seeds, metrics and success criteria fixed before the runs, with the changes
  recorded after the runs.
- `code/` - implementation (`cfgp/core.py`), the CovFourier package v1.3.0 (`covfourier/`), one script per experiment
  (`experiments/`), the figure script (`figures/make_figures.py`); see `code/README.md`.
- `results/` - stored results (JSON; per-data-set arrays in `raw/`); see `results/README.md`. The E1 data sets
  (49 MB) are regenerated from the seeds by `e1_bracket_exact.py` and are not included.
- `figures/` - Figures 1-5 (PDF, PNG), regenerated by `python code/figures/make_figures.py` from `results/` only.
- `borehole_model/` - the borehole modules of the CovFourier package v1.3.0 (`code/applications`) and its stored site
  selection and model-selection files, used by `e8_real_boreholes.py`; found automatically (or set `BOREHOLE_APP`).
- `04_DATA/` - public data: CAMELS-US daily streamflow of the 12 candidate basins (Newman et al. 2015, Addor et al.
  2017; doi:10.5065/D6MW2F4D, CC BY 4.0) and the 2016 NOAA/NCEI borehole profiles (Huang and Pollack). The borehole site
  selection also needs CRUTEM5 (CRUTEM.5.2.0.0, (c) British Crown Copyright, Met Office, Open Government Licence v3):
  place `CRUTEM.5.2.0.0.anomalies.nc` and the station files in `04_DATA/CRUTEM5/` (downloaded from
  http://www.metoffice.gov.uk/hadobs/crutem5; 147 MB, not included). Data paths are found from the archive root, or
  set `CAMELS_ROOT` / `BOREHOLE_ROOT` to the folder that contains `04_DATA`.

Quick check (about one minute): `python code/experiments/f1_idea_data.py` (rewrites results/F1_idea.json; exact log
evidence 698.484...) and `python code/figures/make_figures.py`.
